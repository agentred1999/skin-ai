# Skin AI

A skin analysis web app that uses your camera or photo gallery to scan your skin and provide AI-powered insights.

## Tech Stack
- Next.js 15
- React 19
- TypeScript
- Skinstric API

## Features
- Camera and gallery scan modes
- AI skin analysis and results
- Mobile-responsive diamond UI
- Permission and consent flow

## Setup
```bash
git clone git@github.com:agentred1999/skin-ai.git
cd skin-ai
npm install
npm run dev
```
